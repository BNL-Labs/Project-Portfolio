# Project Portfolio

A collection of seven projects prepared as a single public portfolio repository. The original local project folders remain unchanged; these numbered folders are publication copies with credentials, live records, logs, dependency folders, virtual environments, caches, and generated artifacts removed.

## Projects

| Folder | Original project | Stack | Status |
| --- | --- | --- | --- |
| `Project 1` | Kamas Bot | Node.js, discord.js | Runnable after local configuration |
| `Project 2` | Luxénza.store Bot | Node.js, discord.js, MongoDB | Runnable after local configuration |
| `Project 3` | Ticket Bot v2 | Node.js, discord.js | Runnable after local configuration |
| `Project 4` | UP Ticket | Python, discord.py, Pillow | Runnable after local configuration |
| `Project 5` | UP Welcomer | Python, discord.py, Pillow | Runnable after local configuration |

## Safe setup

Each runnable project contains its own instructions and a safe example configuration. Copy the example file locally, fill in your own values, and never commit the resulting secret file.

Several credentials were present in the original local folders. They are not included here. Those credentials should be rotated at their providers before any deployment.

## Repository layout

The internal structure of each project is preserved as closely as possible. Only publication-risk material was omitted or replaced with neutral placeholders.
